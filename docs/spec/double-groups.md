# Double groups and factor system

Decided in wayfinder ticket
[Double group as a central extension and the factor-system convention](https://github.com/hydeik/pointgroup-tables/issues/4).
Builds on [Abstract groups](./abstract-groups.md) (every element is a pair
`(r, parity)` with `r` in a rotation group `R`) and
[Label conventions](./label-conventions.md). Prototype of everything below:
`prototypes/double_group_prototype.py` (`uv run python
prototypes/double_group_prototype.py` for the self-check over 43 groups, or
pass symbols to print the double group and the factor table).

## Model

The **double group** `G†` of a point group `G ⊆ R × {+1, −1}` is the same
subgroup construction applied to `R† × {+1, −1}`, where `R†` is the binary
cover of the rotation group `R` (a central extension of `R` by `{1, ē}`
with projection `π: R† → R`):

| Type | `G†` |
| ---- | ---- |
| proper | `{(q, +1) : q ∈ R†}` |
| centro | `R† × {+1, −1}` |
| twisted | `{(q, χ(π(q))) : q ∈ R†}` with the same index-2 subgroup `H ⊂ R` |

Products are componentwise. The inversion lifts trivially: the parity is
untouched by the cover, so `G†` has order `2|G|` and the **full turn**
`Ē = (ē, +1)` is its central element covering `E`. For a type II group
`G† = R† × {E, i}`; for a type III group `G† ≅ R†`.

The double group is *not* an invariant of the bare abstract group: `S6`
(`n = 3`, centro, `R = C3`) and `C6` (`R = C6`) are isomorphic as bare groups,
but `S6† ≅ Z6 × Z2` while `C6† ≅ Z12`. The parity carried by the abstract
group is what makes the construction well defined.

## Binary rotation groups

| `R` | `R†` | Element | Product | `ē` | `π` |
| --- | ---- | ------- | ------- | --- | --- |
| `Cn` | `Z_2n` | integer `k̃` mod `2n` | `k̃ + k̃'` mod `2n` | `n` | `k̃ mod n` |
| `Dn` | `Dic_n` | `(k̃ mod 2n, s ∈ {0, 1})`, meaning `a^k̃ b^s` | `(k̃ + (−1)^s k̃' + s·s'·n, s + s')` | `(n, 0)` | `(k̃ mod n, s)` |
| `T` | `2T` | unit quaternion over `Z[1/2]` | Hamilton product | `(−1, 0, 0, 0)` | generator images, see below |
| `O` | `2O` | unit quaternion over `Z[1/2, √2]` | Hamilton product | `(−1, 0, 0, 0)` | generator images |
| `I` | `2I` | unit quaternion over `Z[1/2, φ]` | Hamilton product | `(−1, 0, 0, 0)` | generator images |

`Dic_n = ⟨a, b | a^2n = 1, b² = a^n, b a b⁻¹ = a⁻¹⟩`; the product formula is
that of `Dn` plus the term `s·s'·n`, which records `b² = ē`.

### Quaternion coordinates

A quaternion is a 4-tuple `(w, x, y, z)`. Every coordinate is an element
`(a + b·α) / 2` of the ring `(1/2) Z[α]`, stored as the integer pair
`(a, b)`, where

| `R†` | `α` | `α²` | Elements |
| ---- | --- | ---- | -------- |
| `2T` | `1` (the pair is redundant, `b = 0`) | `1` | the 24 Hurwitz units: `(±1, 0, 0, 0)` and permutations, `(±1, ±1, ±1, ±1)/2` |
| `2O` | `√2` | `2` | `2T` plus the 24 quaternions `(√2/2)(±e_i ± e_j)`, `i < j` |
| `2I` | `φ = (1 + √5)/2` | `φ + 1` | `2T` plus the 96 even permutations of `(±φ, ±1, ±φ⁻¹, 0)/2`, with `φ⁻¹ = φ − 1` |

All arithmetic is integer (the pairs are multiplied with `α² = c·α + d`, the
factor `1/2` is carried as a common denominator); no SymPy is needed to
build `G†`. The sign of a coordinate as a real number (needed by the section
rule below) is decided exactly: for `a + b√2` compare `a²` with `2b²`, for
`a + bφ` write it as `((2a + b) + b√5) / 2` and compare `(2a + b)²` with
`5b²`.

### Generators and the projection onto `T`, `O`, `I`

`R†` is generated by breadth-first closure from two fixed quaternions whose
images under `π` are the permutation generators of `R` fixed in
[Abstract groups](./abstract-groups.md):

| `R†` | `q₁` | `q₂` | `π(q₁)` | `π(q₂)` |
| ---- | ---- | ---- | ------- | ------- |
| `2T` | `(1, 1, 1, 1)/2` | `(0, 0, 0, 1)` | `(1 2 0 3)` | `(1 0 3 2)` |
| `2O` | `(√2/2)(1, 0, 0, 1)` | `(√2/2)(0, 0, 1, 1)` | `(1 2 3 0)` | `(1 0 2 3)` |
| `2I` | `(φ, φ⁻¹, 0, 1)/2` | `(1, φ⁻¹, φ, 0)/2` | `(1 2 3 4 0)` | `(1 2 0 3 4)` |

`π` is the homomorphism determined by these generator images: during the
closure every element `q₁^…q₂^…` is paired with the same word in the
permutation generators. An implementation must check that the pairing is
consistent (a quaternion reached by two words gets the same permutation), that
`π(q) = π(−q)`, and that `π` is onto `R` with fibres of size 2. The three
pairs above pass this check; they were chosen as the first pair, in
coordinate order, among the pairs generating `R†` with no negative
coordinate. Changing a generator changes `π` by an automorphism of `R` and
therefore changes which canonical element carries which sign, so the pairs
are part of the specification.

## Canonical section

A **section** `s: G → G†` picks, for every `g`, one of its two preimages;
`s(g)` is the **lifted element** and `Ē·s(g)` the **barred element** `ḡ`.
The canonical section is, on `R`:

> `s(r)` is the preimage of `r` that is **positive**: for `Z_2n` and
> `Dic_n`, the one whose residue `k̃` lies in `(−n/2, n/2]`; for a quaternion,
> the one whose first non-zero coordinate in the order `(w, x, y, z)` is
> positive.

and on `G`: `s((r, p)) = (s(r), p)`; the inversion is never barred.

Concretely, for `k ∈ [0, n)`: `s(k) = k` when `2k ≤ n`, else `k − n` (mod
`2n`); for `Dn`: `s((k, s)) = (s(k), s)`. Under the standard embedding of
`Dn` in SU(2) (`a` = rotation by `2π/n` about `z`, `b` = rotation by `π` about
`x`) this residue rule coincides with the quaternion rule, so the whole
section is one rule stated on the integer models.

In SU(2) language this is the rotation angle taken in `(−π, π]`, with the
axis of a binary rotation (angle `π`, `w = 0`) taken in the positive
hemisphere; the rotation part of an improper element `i·r` is `r`. This is
the convention of Altmann & Herzig and of the Bilbao double-group tables
(which follow Altmann & Herzig), not the `θ ∈ [0, 2π)` convention. The
choice is consistent with the canonical label rules, which also reduce every
exponent to `|j| ≤ m/2` and pick the positive sign at `j = m/2`.

Consequences that hold in every group:

- every binary rotation squares to `Ē`: `ω(C2, C2) = −1`, also for every
  `C2'`, `C2''` and `C2(k)`;
- `s(C_m^j)` is `s(C_m)^j` for `|j| ≤ m/2`, so `ω(C_m^j, C_m^{−j}) = +1`
  and `ω(C3, C3) = −1` (the lift of `C3²` is not the square of the lift of
  `C3`, since `C3² = C3⁻¹` is lifted with angle `−2π/3`);
- the positive generator of a polyhedral axis (smallest canonical index,
  [Label conventions](./label-conventions.md) rule 5) and its inverse are
  both lifted with `w > 0`.

## Factor system

The **factor system** is the function `ω: G × G → {+1, −1}` defined by

```
s(g) · s(h) = ω(g, h) · s(g h)
```

so that a projective irrep `D` obeys `D(g) D(h) = ω(g, h) D(gh)`. It is
computed from the Cayley table of `G†`: multiply the lifted elements and test
whether the product is `s(gh)` or `Ē·s(gh)`. Values are the integers `1` and
`−1`. The `factor` table is the full `|G| × |G|` array of `ω(g, h)` in the
canonical element order of `G`; its document layout belongs to the output
schema chapter.

Properties an implementation must verify for every group (all exact):

- `ω(E, g) = ω(g, E) = 1` (the section is normalised);
- the cocycle condition `ω(g, h) ω(gh, k) = ω(g, hk) ω(h, k)` for all
  triples, exhaustively for every group tested ([Verification](./verification.md#exhaustive-never-sampled));
- `ω(g, g⁻¹) = ω(g⁻¹, g)`;
- the group axioms on the Cayley table of `G†`;
- `ω(g, h) = ω(r, r')` depends only on the rotation parts, and for a
  type II group the factor system is the pull-back of that of `G⁺`.

## Double group tables

The elements of `G†` are ordered, for `|G| = N` and `g_i` the `i`-th element
of `G` in canonical order:

| Index | Element | Label |
| ----- | ------- | ----- |
| `i` (`0 ≤ i < N`) | `s(g_i)` | the label of `g_i` |
| `i + N` | `Ē · s(g_i)` | `~` followed by the label of `g_i` |

The barred block therefore repeats the canonical order, `Ē` is element `N`
with canonical label `~E`, and `index(ḡ) = index(g) + N`. Reference
conventions spell the bar as they wish (Altmann & Herzig set a tilde, Bradley
& Cracknell a bar); the canonical label is always the `~` prefix.

The optional double-group Cayley table is the `2N × 2N` table in this order.
The element record of a double-group element carries, in addition to the
fields of the [structured element record](./label-conventions.md), `barred`
(`true` or `false`) and `base_index` (the index of `g_i` in `G`). Output
metadata of any double-group table carries `double = true`; the `symbol`
stays that of `G`. Conjugacy classes of `G†` and their relation to those of
`G` are the business of the conjugacy-class chapter.

## Section overrides in label conventions

A reference work may bar the other preimage of some elements (its orientation
of a `C2'` axis differs from the one implied by the canonical rule). Which
preimage is called `g` and which `ḡ` is a labelling question, so a label
convention may carry, per group, the set of elements whose lifts are swapped:

```toml
[barred.D3h]
swapped = ["C2'(2)", "C2'(3)"]      # canonical labels of g whose reference lift is our ḡ
```

Let `ε(g) = −1` for the listed elements and `+1` otherwise. When such a
convention is selected, every table is emitted in the reference section:

- the double-group element list swaps the `~` between `g` and `ḡ` for the
  listed elements;
- `ω_ref(g, h) = ε(g) ε(h) ε(gh) ω(g, h)`;
- projective irrep matrices and characters become `ε(g) D(g)` and
  `ε(g) χ(g)`; ordinary irreps are unchanged.

`ω_ref` differs from `ω` by a coboundary, so nothing about the irreps changes
except these signs. Version 1 ships no `barred` table; the Altmann & Herzig
one is filled from the transcription task
[Transcribe Altmann & Herzig element labels](https://github.com/hydeik/pointgroup-tables/issues/13),
which also records the book's tilde assignments and multiplication tables.
Whether Altmann & Herzig order the positive hemisphere `z`-first or `x`-first
only affects binary rotations of the polyhedral groups and is settled by the
same transcription.
